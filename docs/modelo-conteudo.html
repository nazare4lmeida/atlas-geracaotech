Linguagem de Programação Front-End Dinâmico

⚡ Introdução ao JavaScript

As páginas web modernas são desenvolvidas combinando três tecnologias padrão indispensáveis:

🧱 HTML5 (Estrutura) 🎨 CSS3 (Estilo) ⚡ JavaScript (Comportamento)

O JavaScript é uma linguagem de programação que permite ao navegador atualizar o conteúdo da página dinamicamente, reagindo às ações do usuário e manipulando dados em tempo real.

🌐 Execução no Navegador e Padronização

O código JavaScript é normalmente interpretado e executado pelo próprio navegador web do cliente. Por isso, assim como acontece com o HTML e o CSS, pequenas variações de comportamento podem ocorrer entre diferentes browsers.

Para garantir a consistência e a compatibilidade universal, os principais navegadores aderem à especificação ECMAScript ↗, o padrão internacional que unifica o uso do JavaScript na web.

💡 Esta lição tem como base a especificação ECMAScript em conjunto com a especificação HTML5 ↗, que define exatamente como as rotinas e scripts devem ser incorporados às páginas para que o navegador os execute de forma correta e segura.
